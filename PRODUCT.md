# Smriti Setu

Dementia care support framework for patients (older adults) and caregivers in Assam/India.

## Audience
- Older and middle-aged patients needing calm, high-contrast, large-target UI
- Family caregivers monitoring cognitive trends and reminders

## Jobs
- Patient: daily memory practice, gentle cued reminders, profile/emergency contacts
- Caregiver: weekly summary, domain scores, reminder management, escalation alerts

## Languages
English and Assamese only (in-app toggle).

## Visual commitment
Light, calm adaptation of Veri-style health dashboard language: soft jade accent, simple metric tiles, no dark mode, no neon/glass spectacle. Clarity for older eyes outranks decorative intensity.
